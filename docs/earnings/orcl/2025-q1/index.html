Three things to take away

If you only remember three numbers from this quarter, make it these.

$99B

The backlog jumped 53%

Remaining performance obligations — work customers have signed for but Oracle has not yet delivered — reached a record $99B, up 53% from a year ago. Oracle also signed 42 new cloud GPU contracts worth $3B in the quarter as AI customers booked data-center capacity ahead.

+21%

Cloud is carrying the growth

Cloud revenue — infrastructure plus applications — rose 21% to $5.6B, with cloud infrastructure alone up 45% to $2.2B and cloud applications up 10% to $3.5B. Hardware and services both shrank, so the mix keeps shifting toward recurring cloud rent.

$842M

Debt is the quiet cost

Oracle paid $842M of interest in a single quarter on debt taken on to build data centers and buy back stock. Profit still rose 21%, but interest now eats about a fifth of operating income.
