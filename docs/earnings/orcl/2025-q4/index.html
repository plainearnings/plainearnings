Three things to take away

If you only remember three numbers from this quarter, make it these.

$138B

The backlog jumped 41%

Remaining performance obligations — contracts signed but not yet delivered — reached $138B, up 41% in a year, as big customers committed to Oracle's cloud for AI workloads.

+27%

Cloud kept compounding

Total cloud revenue — applications plus infrastructure — rose 27% to $6.7B, with cloud infrastructure alone up 52% to $3.0B. Oracle said it expected triple-digit growth in MultiCloud database revenue to continue.

$3.4B

Profit grew through the build-out

Net income rose 9% to $3.4B even as cloud delivery costs jumped 33% — Oracle is spending heavily to build AI data centers against that backlog. Non-GAAP EPS was $1.70.
